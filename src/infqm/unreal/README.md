# Create a Camera in Unreal

1. Create a new C++ class in Unreal
2. Name it Camera Stream
3. Add the contents of the CameraStream.cpp and CameraStream.h to the new files
4. Update the Build.cpp with "Sockets", "Networking", "ImageWrapper", "RenderCore"
5. Create a new blueprint from the CameraStream class
6. Place it in the environment
7. Run everything :)
